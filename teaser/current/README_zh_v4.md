# CTR 首页图 · 第四版

主文件为 `ctr_teaser_editable_v4.pptx`，保留一页完整主图及可编辑分组。

本版将 **Irrelevant actions decoupled** 简化为一行 **Open drawer ↔ Pick up cube**，双向箭头中央加紫色叉，表示两个准备动作之间没有必须遵守的时间依赖。Pick up cube 不再有独立外框。

右侧学习器上方的 **Train on both** 已移除。左侧学习结果 **Task order + scheduling bias** 的背景与边框已移除，保留原文字配色。

文件包括完整 PPT、SVG、矢量 PDF、从最终 PPT 渲染的预览和 11 个独立 SVG 模块。具体清单见 `manifest.json`。

图中曲线和关系均为概念示意。独立性针对拾取与开抽屉的准备阶段；放入与关抽屉之间的必要顺序仍被保留。
